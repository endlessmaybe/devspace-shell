让 GPT 接上你的工作台。

三个步骤，开始一段属于你的全新工作记录。

01

选择项目与客户端

填写你自己的路径，安装包不会带入任何旧用户数据。

此桥接依赖兼容的 Windows 桌面客户端。使用独立、已归档的 GPT 执行聊天；配置聊天 ID 是对向该聊天派发任务的授权。其他客户端可使用通用模式或下方 MCP 配置。

模型由你在 GPT 客户端选择。备注不会替你切换模型，也不作为模型身份核验。

02

配对 GPT 的 DevSpace 插件

插件名称随你取。我们核对工具能力，再用一次真实命令回连。

尚未配对

先在 GPT 中安装、启用并授权 DevSpace 插件，再将配对口令发给 GPT。无需提供 GPT 密码、Cookie 或 API Key。

需要 open_workspace、exec_command、write_stdin、apply_patch。工具名称空间和参数必须属于同一个连接器。

03

检查连接，开始工作

完成设置和配对后，即可提交第一个任务。
