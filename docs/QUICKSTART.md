# 第一次使用

下载入口：[GitHub Release](https://github.com/endlessmaybe/devspace-shell/releases/latest)。还没有自己的 DevSpace 服务或插件时，先看 [环境配置](ENVIRONMENT.md)。

## 安装工作台

把完整 ZIP 解压到固定文件夹，双击「一键安装.cmd」。没有 Node 时自动下载官方运行时、核对固定 SHA-256；出现下载失败可稍后再点一次，不会改系统 PATH 或要求管理员权限。应用没有 npm 运行依赖。

默认打开浏览器，并添加当前用户**登录后**自启动。不是关机后还能工作，也不是无人登录时的系统服务。停止或卸载请用安装目录的对应入口；卸载保留个人数据。

## 填写两项设置

项目目录是你要让 GPT 工作的那个文件夹。应用不会帮你复制其他安装的项目、记忆或账号。

命令环境按 DevSpace 实际配置选择。Windows Git Bash 选第一项；WSL2 选第二项。“通用模式”通过复制口令执行；需要持续自动派发时选“桌面隐藏会话 · 自动派发”并先保存。

## 连接专用隐藏会话（桌面模式）

在兼容 Windows 桌面客户端准备一条专用 GPT 会话，启用 DevSpace 插件后归档。回到 Shell 点击“识别隐藏会话”，按名称选择并连接。**不需要手填调用方或目标聊天 ID。**

如果弹出首次连接口令，把它发给兼容 Codex 桌面客户端，让其使用本地终端工具执行一次；脚本自动获取调用上下文。回到 Shell 再识别并选择隐藏会话。第一次绑定后保存在本机，重启不需要再次绑定。

归档隐藏并不等于临时聊天或关闭记忆；需要记忆隔离时请核对客户端专用会话的记忆设置。Shell 不更改全局开关，也不自动创建普通 GPT / 临时聊天。详细行为与限制见 [隐藏执行器说明](HIDDEN_EXECUTOR.md)。通用模式跳过这一步。

## 连接 GPT

先在 GPT 中安装并启用 DevSpace 插件，确认有 codex 模式的四项工具能力，再点击「生成配对口令」。将完整口令发送给 GPT，让它核对当前实际工具并执行回连命令。插件可以叫任何名字。桌面模式请在已选的专用会话中完成配对，并保持该会话归档；随后勾选自动派发并保存设置。

GPT 若报告缺工具，请看 [插件识别说明](PLUGIN_COMPATIBILITY.md)。不要输入账号 Cookie 或把认证链接发给其他人。安装包本身不包含 DevSpace 插件或 GPT 账号。

## 创建任务

进入工作台，点「新建任务」，写清目标与验收方式。任务会保存到本机。在通用模式中点「复制执行口令」并发给 GPT；桌面自动模式中则按队列依次派发。

GPT 实际领取后才显示「运行中 · RUNNING」。任务执行协议要求定期回报进展、保存检查点和验证证据。已发送、服务在线、心跳成功都不是任务完成。

## 中断之后

重启不会清空任务和检查点。若看到「租约过期」或「发送结果未知」，先查看原 GPT 聊天和已经执行的命令，停止旧执行器后再明确恢复原任务。控制台不会为了看起来一直在运行而反复发送同一个可能有副作用的任务。

选择暂停只撤销本地继续写回的租约，不能撤销已发生的文件修改，也不能替你停止所有 GPT 客户端。请在 GPT 端同时停止执行。
