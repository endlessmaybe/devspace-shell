## 验收边界

本地 Windows 实机和模拟协议测试不等于在所有 GPT 客户端、所有账户、macOS/Linux 桌面环境中真实登录验收。完整 GPT/OAuth 接入需要安装使用者自行授权自己的 DevSpace 插件。私有桌面管道只能在兼容版本中使用；它不是跨客户端通用接口。

安装包不会附带发布者的聊天或账号来替代这一步。长时间自动工作还依赖用户设备、客户端登录、网络与模型额度；故障恢复不会擅自重放不确定操作。
