# 本地记忆

Shell 0.1.3 内置本安装自己的长期记忆。首次安装没有任何记录；升级从空白记忆表开始，不扫描旧任务、其他安装、聊天或用户文件。用户可逐步保存自己的偏好和知识。

## 在工作台管理

点击左侧「本地记忆 · 偏好与知识」。

- **当前项目**：保存项目知识、验证过的环境事实、适用条件和项目偏好。不同项目按真实绝对路径隔离；符号链接/Windows 大小写别名归为同一项目，移动项目不会自动迁移记忆。
- **用户偏好 · 所有项目**：显式保存希望每个项目采用的偏好，例如输出语言。该范围只用于偏好，不把项目知识自动提升为全局规则。
- **搜索**：支持中文相邻字组、单字与英文前缀，按关键词相关度、固定标记和更新时间排序。这是本机全文检索，不是向量语义搜索。
- **新增/修改**：记录标题、内容与依据；可固定重要条目。内容最多 12000 字符。并发修改会提示刷新，不静默覆盖其他客户端的修改。
- **删除/清空**：移除检索索引与选定范围内的条目；用户删除或编辑的自动任务记录不会被该任务的后续自动回执覆盖/重建。其他项目不会被清空。
- **导出**：导出选定范围的 JSON，不包含 Shell 凭据、配置或其他项目。文件含用户自己的内容，应妥善保管。没有自动导入其他安装的功能。

删除记忆不删除原任务/检查点，不撤回已经发送给 GPT 的内容，也不保证 SQLite/WAL 或设备备份中的物理擦除。固定记录、手动编辑后的记录和显式知识不会因自动保留上限被删除。

## 自动保存与后续任务

默认开启本地记忆及自动记录。每次真实检查点或完成回执，在同一事务中更新该任务的一条项目记忆，记录检查点、结果与验证证据的有界摘录。心跳、领取与普通活动不会生成自动记忆。相同 `commandId` 重试不会重复写入。

自动记录不是模型自行推导的结论，也不是独立验证器。检查点最多摘录 5000 字符，结果最多 4000，证据最多 2000；完整内容仍在原任务中。每项目默认保留最近 200 条未固定自动记录，可设置为 1–1000；不会裁剪原任务历史。

新任务、恢复后重新生成的口令、自动派发及 MCP 读取任务都会检索当前项目的相关知识，并优先考虑显式用户/项目偏好。每次最多 12 条，记忆条目 JSON 合计最多 8000 字符，每条内容最多 3000 字符。预算有限，不保证每次提供全部记忆；重要内容可以固定，具体任务仍应写清硬性要求。

记忆放在明确标注的 JSON 引用数据段。历史内容可能过时或含不可信文本，不能覆盖当前用户指令或 AGENTS.md，也不能授予新权限。执行器应先核实再行动。不要保存密码、令牌、私密聊天或文档中的恶意指令。

## 其他客户端与执行器

设置页生成的标准 stdio MCP 配置继续可用，新增：

- `devshell_search_memory`：给定项目和关键词，读取有界项目知识与用户偏好。
- `devshell_remember`：持有效任务租约，为当前任务项目新增核实过的知识或项目偏好。需要稳定 `commandId`；不能写其他项目/用户范围，不替代业务进展或心跳。
- `devshell_get_task`：同时返回任务、活动与当前检索上下文。

复制口令提供 `client.mjs task --action memory` 检索和 `--action remember` 保存示例。任务票据只可读取本任务项目与显式用户偏好，不能访问工作台管理接口。偏好编辑、删除和清空由已认证的本机工作台完成。

## 开关、持久化与隐私

在「记忆设置」关闭本地记忆后，不再向任务提供记忆，也拒绝执行器写入、停止自动记录；原记录保留，仍可在工作台管理。只关闭自动记录则保留检索和显式知识保存。重启会保留设置、记忆、任务及租约。

记忆与 FTS 索引存在本安装数据目录的 `tasks.sqlite`，采用 WAL/FULL 事务。Windows 默认位置为 `%LOCALAPPDATA%\DevSpaceShell\data`；可用 `DEVSPACE_SHELL_DATA` 指定独立数据目录。源码和 Release 白名单排除数据库、运行配置、日志及私人内容。

选中的记忆会随任务送给用户配置的 GPT 执行器。因此“本地存储”不表示执行时永不离开电脑。Shell 不调用向量服务、不创建外部记忆账户，也不会上传记忆到本项目 GitHub。

本地记忆开关与 **ChatGPT 账号记忆设置独立**。归档隐藏聊天也不等于临时聊天。Shell 不更改账号全局记忆，当前桥接不能核验专用聊天是否关闭平台记忆；需要账号级隔离时应在自己的客户端核对设置。

## 升级

停止当前 Shell，解压完整新版到程序目录，保留原数据目录，再运行安装器更新启动项。首次启动只新增记忆表与索引，不改变任务 ID、租约、检查点或专用隐藏会话绑定。无需复制旧部署的个人记忆或重新填写聊天 ID。
