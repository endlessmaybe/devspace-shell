# 后台专用隐藏会话

桌面模式沿用专用的**已归档 GPT 会话**，由本地后台持续派发。任务不会送到用户日常聊天。会话 ID 是内部路由信息，0.1.2 起无需用户查找或手填；连接一次后保存在本安装的数据目录，重启继续使用。

## 第一次连接

1. 在兼容 Windows 桌面客户端中准备一条独立 GPT 聊天，选择自己的模型并启用 DevSpace 插件。不要把已有个人聊天当作后台执行器。按客户端提供的选项设置这条专用会话的记忆，然后将其归档。
2. 在 Shell 填好项目目录，选择“桌面隐藏会话 · 自动派发”，先保存设置。
3. 点击“识别隐藏会话”。如果 Shell 启动环境已有桌面调用上下文，直接显示归档列表；否则会生成“首次桌面连接”口令。将口令发给兼容 Codex 桌面客户端，让它使用**本地终端工具**执行一次。脚本从工具环境自动读取调用上下文，不需要用户输入 ID，也不查找客户端配置或数据库。口令十分钟内有效，只能使用一次。
4. 回到 Shell，再点击“识别隐藏会话”，按名称选择刚准备的专用 GPT 会话，点击“连接所选隐藏会话”。即使列表中只有一条，也不会自动替用户选定。列表支持加载更多。
5. 将 DevSpace 插件配对口令发到这条专用会话中，完成实际命令回连，保持会话归档。勾选“自动依次派发我提交的任务”并保存。

后续只需让桌面客户端保持开启和登录。后台持久保存绑定；环境里出现另一个聊天上下文也不会偷偷覆盖原绑定。无需每次请 Codex 接管或再次填写信息。

首次桌面连接和 DevSpace 插件配对是不同的单次口令：前者获得客户端调用上下文，后者核对实际 DevSpace 工具并验证命令回连，两者不能互相替代。若本地终端工具没有提供 `CODEX_THREAD_ID`，会明确报告不支持；不会猜测 ID、扫描聊天文件或使用发布者的绑定。

## 隐藏、临时聊天与记忆

**归档只意味着从常规列表隐藏，不等于临时聊天，也不能证明记忆已经关闭。** 本软件不读取、导入或管理用户长期记忆，不更改全局记忆开关；识别和连接只读取归档列表的 ID、标题与更新时间，不读取聊天正文和摘要。

需要避免 GPT 创建长期记忆时，应使用客户端相应的专用会话记忆选项或适用的临时聊天模式，并自行确认插件是否可用。当前桌面公开桥接只支持本项目已实现的归档会话派发，**没有创建普通 GPT / 临时聊天或验证其记忆设置的接口**，因此 Shell 不宣称已自动建立“零记忆”临时会话。也不调用 Work Cloud 创建工具来替换用户选定的网页模型。

不希望使用此桌面桥接的客户端可使用通用执行口令或标准 MCP 任务连接器；同样不需要聊天 ID。

## 升级与异常

0.1.0 / 0.1.1 已有绑定原样保留，不重新选择会话，不清空任务。新版设置页只显示绑定状态及会话名称；保存普通设置不会覆盖绑定。

用户解除归档或删除所选聊天后，派发前的身份、归档与空闲检查会阻止错误发送。请恢复原专用会话的归档，或先处理原任务、核实副作用，再回设置页重新连接。不会自动换到列表中另一条聊天。

调用上下文失效时使用“首次连接 / 重连桌面”重新生成口令。执行槽被任务占用时禁止换上下文或目标；检查点、租约及未知发送证据保留。429 冷却适用于识别、绑定与派发，不能靠换管道绕过。
