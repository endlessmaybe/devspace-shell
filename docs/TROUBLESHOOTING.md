# 排错

| 看到什么 | 原因与处理 |
| --- | --- |
| 双击没有完整程序 | 解压完整 ZIP，不能只下载 `.cmd`。路径需可写，推荐自己的普通文件夹。 |
| Node 下载失败 / 校验失败 | 检查到 `nodejs.org` 的网络。校验失败不会执行下载文件；删除提示的 `.runtime` ZIP 后重试。已有 Node 24–26 时可使用 `Install.cmd -NodePath "完整 node.exe 路径"`。 |
| 控制台要求从启动器打开 | 本机认证未带入或浏览器会话被清除，重新双击「启动Dev.cmd」。不要手工分享带 token 的链接。 |
| 地址不是 17861 | 首选端口被占用时选后续可用端口；使用启动器打开的实际地址。应用不会杀占用者，也不会修改原有 Dev 安装。 |
| MCP 检测返回 401 | 需要 DevSpace OAuth。先在 GPT 里启用并授权插件，再使用配对口令；Owner 密码不是 Bearer Token。 |
| 找不到完整工具 | 确认 DevSpace 使用 codex 模式：1.0.8 设置 `DEVSPACE_TOOL_MODE=codex`；1.1 在自己的 JSONC 设置 `tools.mode`。重启自己的服务，再刷新客户端目录。插件显示名随意，但四项工具与参数必须匹配。 |
| 找到多个插件 | 让 GPT 明确列出候选，请你选择。只提交所选插件的目录重新配对，避免混用不同机器或连接器。 |
| 配对命令找不到 Node 或目录 | 使用口令中的绝对路径，确认 Shell 与 DevSpace 在同一设备。WSL 需 Windows interop；检查设置中的命令环境并重新生成口令。 |
| WSL 无法访问回环地址 | 口令的回执命令应通过指定 Windows Node 调用，而不是把地址随意换成公共网卡地址。不要公开控制台或关闭防火墙。 |
| 桌面桥接不可用 | 仅支持兼容 Windows 桌面客户端；确认客户端开启且已登录。其他客户端保持通用模式或使用标准 MCP 任务配置。 |
| 目标聊天不在归档 / 身份不符 | 检查你自己的调用方和目标聊天 ID；目标必须是独立的已归档 GPT 聊天。不会自动换到其他聊天。 |
| 等待 GPT 领取 | 只表示发送已确认。检查 GPT 端是否生成、是否启用插件、是否执行领取命令。不能把这个状态改成 RUNNING 冒充执行。 |
| 发送结果未知 | 原消息可能已送达。查看原 GPT 聊天及文件副作用；只有确定未送达后才点击对应确认。不会自动重发。 |
| 租约过期 | 保留原任务和断点。核实并停止原执行器后恢复，执行器重新领取新租约。 |
| 429 / 客户端额度耗尽 | 本地持久冷却，等待额度恢复。不更换账号或用第二根管道绕过限制。 |
| 开机后未工作 | 登录自启动需要该用户实际登录，源码目录不能被移动/删除。移动后重跑安装器。桌面自动派发还要求客户端启动并登录。 |
| `start.lock` 遗留 | 先用状态检查确认本安装未运行，并查看数据目录 `service.log`。确认没有本程序启动器后，仅删除该数据目录的 `start.lock` 空文件夹再重试。不要按端口杀进程。 |

日志、任务数据库和配置都在设置页显示的本机数据目录。排错公开信息只提供错误说明和已遮盖的截图，不提供配置凭据、认证链接、任务口令、数据库或完整项目日志。

```powershell
./Install.cmd -Action status
./Install.cmd -Action stop
./Install.cmd -NoAutoStart
```

停止服务保留所有任务；卸载入口移除自己的自启动并保留数据。需要完全清除个人历史时，在应用停止后备份或删除**本安装**的数据目录；切勿删除其他 DevSpace 安装的数据。
